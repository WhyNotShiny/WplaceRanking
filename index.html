How To Use
  1. 1Click any cell on the map — the hit area scales with zoom, so corners still register when you're zoomed in close.
  2. 2Search by name, Region ID, or country name, or sort by rank / Region ID using the chips above the list.
  3. 3Click a row (or its locate button) to fly there and highlight it in the list — clicking the map does the same in reverse. The second button opens that region directly on wplace.live.
  4. 4Drag the sidebar's right edge to resize it, or hit the ◀ button in the header to collapse it entirely.
  5. 5The Stats tab breaks down the pixel distribution — trimmed mean, deviation, and percentile spread across all regions.
  6. 6Map color follows a log scale — purple/blue is low pixel density, pink/red is high (see the legend, bottom-right).
  7. 7Use the timeline slider at the bottom of the map to compare snapshots across different dates. Use ← / → arrow keys to step between dates, or drag the slider. Each CSV is cached after the first load so switching is instant.
  8. 8The grid button (top-left of the map) hides the base map and place labels, leaving just the coloured region squares.
  9. 9Selecting a region draws a red box around it on the map. Clicking a country in the Countries view washes all of that country's regions in white and fits the map to show them.

/ jumps to search · Esc clears focus, closes popups, and deselects the current region/country · ← → steps through snapshot dates
